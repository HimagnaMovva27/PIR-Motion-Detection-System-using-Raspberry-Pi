# PIR Motion Detection using Raspberry Pi

##  Description
This project implements a motion detection system using a PIR (Passive Infrared) sensor with Raspberry Pi. The system detects human movement based on infrared radiation and provides real-time output.

##  Components Used
- Universal IOT trainer kit with raspberry pi
- PIR Sensor
- Jumper Wires
-Connecting Wires
- USB Cables

##  Connections
- PIR OUT → GPIO 23  
- PIR VCC → 5V  
- PIR GND → GND  

##  Working Principle
The PIR sensor detects changes in infrared radiation caused by human motion. When motion is detected, the sensor outputs a HIGH signal, which is read by the Raspberry Pi through GPIO.
